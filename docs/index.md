# Stroke Prediction Dashboard

Bienvenue dans la documentation du projet **Stroke Prediction Dashboard**.  
Cette application permet de visualiser et d’analyser des données liées aux accidents vasculaires cérébraux (AVC) à partir d’une API FastAPI et d’une interface Streamlit.

---

## Objectifs du projet

- Visualiser les patients et leurs caractéristiques médicales et sociales.  
- Explorer les statistiques liées aux AVC.  
- Fournir un outil d’aide à la décision médicale.
